# Changelog / 更新记录

## v0.1.0 — 2026-10-17 — Beta / 测试版

- Restore supported mod hero cameras from each hero's currently installed original assets, including compatible transformation models.
- Synchronize gameplay camera attachments, associated FOV metadata and camera settings.
- Provide scan, repair, expanded-scope repair and restoration launchers.
- Verify model data and VPK resources, back up modified files, and disable the uniform global-camera override through a marked startup block.
- Include Chinese and English instructions, disclaimers, GPT authorship disclosure and third-party license notices.

中文：

- 按各英雄当前原版资源修复受支持 MOD 的相机，包含兼容的变身模型。
- 同步游戏相机挂点、相关 FOV 元数据及相机设置。
- 提供扫描、修复、扩大范围修复及回滚入口。
- 校验模型及 VPK 资源、备份修改前文件，并通过带标记的启动配置关闭统一全局相机覆盖。
- 提供中英文说明、免责声明、GPT 制作声明及第三方许可证。

Tested reference / 开发测试参考：Deadlock build `25999968`.

This beta is unofficial and is not guaranteed to be ban-safe. Windows, Python 3.10+ and PowerShell 7.6 / .NET 10 are required. Unsupported models are reported and skipped. Rerun after game or mod changes.

本测试版非官方，不保证零封禁风险。需要 Windows、Python 3.10+、PowerShell 7.6／.NET 10。不支持的模型会报告并跳过；游戏或 MOD 变化后应重新运行。
