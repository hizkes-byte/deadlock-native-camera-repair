# Deadlock 原版相机通用修复工具

**为每个英雄恢复其自身的原版相机数据，而不是统一所有英雄的机位。**

自定义脚本及文档主要由 **OpenAI GPT 通过 Codex** 根据发布者需求生成和修改，使用第三方 Source 2 解析库。本工具非官方，**不保证零封禁风险**。运行前请阅读[免责声明与 GPT 制作说明](DISCLAIMER.zh-CN.md)。

[English instructions](README.en.md) · 文档更新：2026 年 10 月 17 日

## 1. 准备环境

- Windows、Steam、已安装的 Deadlock，以及需要修复的英雄 MOD。
- **Python 3.10+、PowerShell 7.6（基于 .NET 10）**。只有 Windows PowerShell 5.1 或只安装 .NET 10 不够。
- 启动器优先使用本机已有且受支持的 Codex 配套运行时；否则需要命令行可访问的 `python.exe` 和 `pwsh.exe`。本包不附带运行时，也不会自动安装。
- 预留足够磁盘空间：扫描会生成模型和修复副本，正式修复还会备份完整 VPK，占用可能超过 MOD 原大小。

将**整个压缩包解压**到可写、便于长期保留的目录。不要在 ZIP 内运行，也不要只复制一个 `.cmd`。保留 `lib/`、`licenses/` 和其他随包文件。

## 2. 推荐流程

1. **退出 Deadlock，关闭 MOD 管理器**，暂停更新，并保存重要 MOD 的独立备份。
2. 双击 `Scan.cmd`。它自动定位游戏，生成报告和修复副本，**不替换游戏文件、不改变启动配置**。
3. 查看窗口末尾的结果及 `Report:` 路径，特别留意 `UNSUPPORTED`。扫描完成不代表全部模型受支持。
4. 双击 `Repair.cmd`。它重新检查当前文件，校验修复副本，备份原文件并安装结果，同时关闭全局相机覆盖。
5. 正常完成后再启动游戏，在训练场检查移动、站立、蹲下、瞄准、贴墙和变身。训练场测试不能证明联机使用无封禁风险。

请停止使用此前的“统一全局视角”方案，避免启动设置互相覆盖。

## 3. 启动文件

| 文件 | 功能 |
| --- | --- |
| `Scan.cmd` | 扫描默认范围，生成报告和修复副本，不安装。 |
| `Repair.cmd` | 修复默认范围，备份并安装，关闭全局相机覆盖。 |
| `Repair-Including-Disabled.cmd` | 扩大到 addons 中其他单文件 VPK，可能修改停用 MOD；通常不必首先使用。 |
| `Restore.cmd` | 回滚本工具目录中最近一次成功安装且尚未回滚的运行，包括该次修改的启动配置。 |

默认范围按 `pak数字_dir.vpk` 文件名识别，并非读取所有管理器的启用状态。其他命名方式的 MOD 可能需要扩大范围。

## 4. 改动范围

工具从本机 `game/citadel/pak01_dir.vpk` 及官方分卷读取原版参考，**不改写官方资源包**。对路径精确匹配、骨骼兼容的模型，同步站立、蹲下、远近镜头、瞄准挂点，以及相关 FOV 元数据和 `CitadelCameraSettings_t`，并检查其他模型数据和 VPK 资源的一致性。

正式修复还会在 `game/citadel/cfg/autoexec.cfg` 末尾维护带标记的配置块，设置：

```text
citadel_camera_overrides_enabled "false"
```

这会让游戏使用各英雄自己的相机配置。已有启动配置保留并备份，不会为全部英雄指定统一距离或高度。

## 5. 结果、报告和备份

| 提示 | 含义 |
| --- | --- |
| `changed` | 存在相机差异，已生成并检查模型修复。 |
| `native` | 无需修改，也可能是无需游戏相机修复的配件模型。 |
| `unsupported` / `UNSUPPORTED` | 模型或包无法自动处理，查看具体原因。 |
| `archives` | 需要修改的 VPK 数量。 |
| `startupChanged` | 是否需要修改原版相机启动配置块。 |
| `applied=True` | 本次实际安装了变更；扫描或无需修改时可能为 `False`。 |

每次运行的报告位于 `runs/时间戳-编号/report.json`。`models` 列表记录模型状态，`archives` 列表记录文件变更，也可能包含启动配置。原文件备份在同一运行目录的 `backups/`。

如需自动回滚，请**保留完整工具目录，不要移动运行目录或单独删除备份及生成的修复副本**；报告记录了绝对路径。

## 6. 回滚

退出游戏和管理器，运行原工具目录中的 `Restore.cmd`。它核对当前文件与备份的 SHA256 后，恢复该次运行前的状态。若之后已更新、重排或重装 MOD，或修改相关配置，回滚可能拒绝覆盖；请保留报告和备份，先检查版本差异，不要绕过校验。

**回滚恢复的是运行前的 MOD 状态，不等于卸载 MOD 或恢复完全原版游戏。** 停用全部 MOD 需要另外处理 MOD 管理器及加载配置。

## 7. 兼容性与重新运行

目前支持单文件 VPK v1/v2 MOD 和内嵌 MDAT 网格相机。没有精确原版路径、不兼容骨骼、MOD 分卷、预载模型条目、外部网格相机等情况会跳过；同一 VPK 的其他受支持模型仍可能修复。

这是批量修复器，不是永久的运行时相机锁。更换皮肤、启停或重排 MOD、重装 MOD、更新游戏后，应重新检查并修复。未来格式改变可能导致不兼容；特殊技能、姿态或模型遮挡引起的问题也可能仍存在。

## 8. 自定义路径与排错

自动定位失败时，在解压目录打开 PowerShell，指定 **`game/citadel`，不是 addons 或游戏根目录**：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Repair.ps1 -Mode scan -Citadel "D:\SteamLibrary\steamapps\common\Deadlock\game\citadel"
```

确认扫描后，将 `-Mode scan` 改为 `-Mode repair`。也可使用 `-Addons "完整MOD目录路径"` 指定 MOD 目录。

- **缺少运行环境：** 安装相应版本并加入 PATH，重新打开终端。用 `python --version` 检查 Python；用 `pwsh -NoProfile -Command "[Environment]::Version"` 检查 .NET，主版本应为 10 或更高。
- **文件变化或校验失败：** 关闭管理器、等待更新完成，再重新扫描。
- **不支持模型：** 查看报告原因，等待工具或 MOD 作者适配。
- **无可恢复的运行：** 确认工具目录、`runs/`、报告和备份仍完整且位于原位置。
- **系统策略阻止执行：** 核实来源并遵循设备管理规定，不要关闭安全软件。
